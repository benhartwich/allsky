Conditions dialog – three redesigns

Mockups for Allsky's overlay conditions (AllskyTeam/allsky#5290). Same features as the current dialog; the example is a ${GAIN} field. Type in Try a value to see which rule is used.

A · Colour firstrules as rows, colour is the big control

Each rule reads like a sentence: when value < 100 → green. The colour swatch and a sample of the value are the largest things in a row; extra styles (stroke, opacity, font) are behind a small icon. Rule sets move into one menu. "+ and" becomes the operator between.

C · Colour bandsfor numbers: thresholds like a gauge

Most number conditions are ranges (cold / normal / hot). Here the whole range is one bar: click a band to pick its colour, type the limits between bands. No operators, no "and", no ordering. Yes/No variables get two cards; text variables would use the rows from A.
